# Tail PnL Diagnostic Report Design

- Audience: product and strategy stakeholders.
- Reading path: answer first, distinguish displayed simulator output from realized Paper PnL, then explain the statistical and execution mechanisms.
- Visuals: grouped checkpoint bars for BTC versus the full asset pool; grouped sign counts to expose negative rows hidden by an all-green BTC slice.
- Semantic rule: positive simulated PnL is not labeled as verified live edge.
